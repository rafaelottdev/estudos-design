# Estudos Design

Repositório criado para documentar meus estudos em Design durante minha jornada como desenvolvedor front-end.

O objetivo deste repositório é armazenar:
- conceitos fundamentais de design
- princípios visuais
- anotações
- estudos teóricos
- referências visuais
- exercícios e práticas
- materiais de apoio

Tudo organizado conforme avanço no entendimento de UI/UX e fundamentos visuais.

---

# Objetivos

- Aprender princípios fundamentais de design
- Entender composição visual
- Melhorar percepção de UI/UX
- Aplicar design em projetos front-end
- Desenvolver senso estético e hierarquia visual
- Estudar boas práticas de interface
- Criar base sólida para design de aplicações

---
